# Student Portal Dashboard

A static HTML/CSS prototype for a student dashboard interface.

## Overview

This project contains a single page student dashboard mockup built with HTML and inline CSS. It showcases a dark-themed layout with a sidebar, user profile, dashboard metrics, and log cards.

## Files

- `mv1.html` — main dashboard UI prototype
- `README.md` — project overview and usage guide

## Features

- Responsive dark theme layout
- Sidebar navigation panel
- Dashboard cards for metrics and system status
- Activity log section
- Clean and modern visual design

## How to open

1. Open `mv1.html` in a web browser.
2. No additional setup or server is required.

## Notes

- This is a static frontend prototype only.
- You can extend it by adding JavaScript, backend integration, or additional pages.
